Hands-On Guide

Create, save, and reopen your first equation.

Open any editable Markdown note in Obsidian’s desktop main window to test the full round-trip workflow.

  1. Launch the editor

    Click ∑ in the note header or left ribbon, then select Visual → Math → Fraction.

  2. Fill placeholders & edit LaTeX

    Type 3, press Tab, and type 4. Switch to LaTeX and append +1.

  3. Inspect in Hybrid & insert

    Select Hybrid to verify the synchronized LaTeX and rendered formula, then click Insert equation.

  4. Verify persistence

    Close the note tab and reopen it. Place the cursor inside the saved equation and click ∑ to continue editing (or pick it from the formula selector).

FAQ & Specifications

Frequently asked questions.

Have a question or a reproducible bug report?

Open an issue on GitHub ↗
Does Visual Math run in the browser?

No. Visual Math is a native desktop plugin for Obsidian. This website provides documentation, real-software previews, and installation links.

Which platforms and Obsidian versions are supported?

Requires Obsidian 1.14.4 or later on desktop. Native release checks were verified on macOS with Obsidian 1.14.5 (targeted 1.0.0 acceptance) (and Obsidian 1.14.4 for v0.8.2 media captures). Windows and Linux have not been verified. Mobile is not supported.

Do I need an account, API key, or Node.js?

No runtime account, API key, or Node.js installation is required for the compiled plugin. All editing, scientific reference tables, and graphing tools run locally. Network access is only needed when downloading or updating the plugin.

Does editing a saved equation automatically update an existing graph?

Live equation/graph preview is linked only while its editor is open. Saved formula and graph are separate blocks; navigation persists only when explicitly saved. Editing a saved equation later does not automatically overwrite a previously inserted graph. After panning, zooming, or rotating a graph, click Save view or Save graph to persist the updated state.

Is Visual Math a symbolic CAS or general equation solver?

No. Graphing and calculus views use numerical evaluation within supported domains and finite, increasing, continuous intervals. They produce numerical approximations and are not a symbolic computer algebra system or general equation solver.

How are long LaTeX expressions and unsupported macros handled?

In 1.0.0, guarded single-equation import accepts single formulas up to 120,000 characters (rejecting multi-equation documents, $$...$$ blocks, and document-level preambles). Standard visual editing uses an 8,192 UTF-16 input budget and a 4,096-unit visual complexity budget; expressions exceeding the visual budget or containing custom TeX macros remain editable in source-only LaTeX mode. Custom formula keywords from earlier betas were removed in 1.0.0.

What license does Visual Math use?

GNU GPL version 3 only with the Obsidian linking exception. Review the full licensing terms and third-party notices on GitHub.
