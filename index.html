A TOOLKIT FOR SCIENTIFIC NOTES

More of the working.
Less of the friction.

Nine focused capabilities in 1.0.0 Stable —
from guarded formula import to matrices, geometry and local graphs.

∑

Visual, LaTeX and Hybrid equation editing

Insert and reopen inline or display LaTeX formulas, including fractions, roots, scripts, integrals and sums.

Scope & limits

Unknown macros and complex TeX may require source editing.

⌁

Function, polar, complex-plane and XYZ graphs

Plot supported explicit y=f(x), r=f(theta), z=f(x,y), and rectangular complex points locally.

Scope & limits

Numerical approximations; no general implicit/parametric solver, symbolic algebra, overlays or sliders.

∫

Numerical calculus views

First and second numerical derivatives and finite definite integration for supported real functions.

Scope & limits

Not symbolic differentiation/integration; finite increasing continuous intervals only.

H₂

Chemistry and physics writing tools

Format chemical notation, use bounded balance suggestions, insert physics symbols and editable templates.

Scope & limits

Balance suggestions do not establish reaction feasibility; no molecular or physics simulation.

⇄

Units and periodic table

Convert among 63 preset unit choices in 11 categories; look up 118 elements.

Scope & limits

Within-category preset conversion and local reference data; no arbitrary dimensional analysis.

⟨⟩

Guarded single-equation import

Review original and candidate, recognize one outer math wrapper, explicitly Apply/Cancel and Save; preserve exact source.

Scope & limits

8192 UTF-16 original-input units; visual budget4096 plus structural limits. Longer valid or unknown notation is source-only, not full visual support. No batch/file/OCR/document import or mathematical repair.

⌈⌉

Visual matrices and equation systems

1–6 rows/columns for matrix cells;2–6 single-column rows with an automatic left brace for systems. Preview, apply, cancel and draft Undo/Redo.

Scope & limits

Notation editing, not matrix calculation or an equation solver. Native1.0.0 acceptance targeted a two-row system; broader matrix behavior passed components.

∈

Advanced notation, sets and sequences

Nine advanced-math templates,19 set/sequence tools and common trigonometric/geometric notation.

Scope & limits

Editable notation without symbolic evaluation or proofs.

△

Geometry models and basic spatial relations

Seven adjustable models and three scenes: two planes,line–plane,sphere–plane. Save dimensions,face visibility,rotation and zoom in vme-plot blocks.

Scope & limits

Fixed bounded analytic scenes; no arbitrary solid intersections or CAD.1.0.0 passed component/logic round trips; historical representative native evidence remains version-specific.

◈

Your workspace stays local. No runtime account or network connection is required. Downloading and installing the plugin needs access to its distribution source.

YOUR FIRST EQUATION

A fraction. A small addition.
Your first saved formula.

Use an editable Markdown note in
Obsidian’s desktop main window.

  1. Open the editor.

    Click ∑ in the note header or ribbon. Choose Visual → Math → Fraction.

  2. Build the fraction.

    Enter 3, press Tab, then enter 4. Switch to LaTeX and append +1.

  3. See both, then insert.

    Choose Hybrid to see the source and formatted equation. Choose Insert equation.

  4. Close. Reopen. Keep thinking.

    Close the note tab and reopen it. Put the cursor inside the saved equation, then click ∑ to edit again. Choose it from the picker if prompted.

A FEW USEFUL DETAILS

Before you
get started.

Have a question or a reproducible issue?

Talk to us on GitHub ↗
Does Visual Math work in this browser?

Visual Math runs inside Obsidian on desktop. This website introduces the plugin and helps you install it in a vault.

Which devices can I use?

This release requires Obsidian 1.14.4 or later and is desktop only. Native checks have used macOS with Obsidian 1.14.5 (targeted 1.0.0 acceptance) (and Obsidian 1.14.4 for v0.8.2 media and earlier checks). Windows and Linux have not been verified. Mobile is not supported.

Do I need an account, API key or Node.js?

No runtime account, API key or Node.js is required for the compiled plugin. The editor, bundled data and graph tools run locally. Downloading and installing requires access to the distribution source.

Will an edited equation update its saved graph?

Live equation/graph preview is linked only while its editor is open. Saved formula and graph are separate blocks; navigation persists only when explicitly saved. Changing a saved equation later does not automatically update an existing graph. After moving, zooming or rotating a graph, explicitly choose Save view or Save graph to keep the changes.

Can it solve any equation or calculate symbolic integrals?

Graphing and calculus use numerical methods within supported domains. They are not a general equation solver or symbolic algebra system. Numerical calculus is for supported real functions on finite, increasing, continuous intervals; results are approximations.

What if my LaTeX does not render visually?

Unknown macros and complex TeX may need source editing. In 1.0.0, guarded single-equation import accepts up to 8,192 UTF-16 code units of original input with a 4,096-unit visual budget; longer valid expressions and unknown macros can be saved in source-only mode. Visual editing does not support every TeX command.

How do I report a problem?

Open a GitHub issue with your plugin version, Obsidian version, operating system and exact steps. Include a small example you are comfortable sharing. Check existing issues first.

What license does the plugin use?

GNU GPL version 3 only with the Obsidian linking exception. See the licensing details for the full terms and third-party notices.
