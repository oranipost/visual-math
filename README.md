# Visual Math for Obsidian

Official promotional website: [https://oranipost.github.io/visual-math/](https://oranipost.github.io/visual-math/)

Visual Math is a desktop Obsidian plugin. Install it from the [official community directory](https://community.obsidian.md/plugins/visual-math-editor).

[Plugin repository](https://github.com/oranipost/visual-math-editor) · [Official YouTube channel](https://www.youtube.com/@VisualMathForObsidian)

This repository contains the reviewed static website export. GitHub Pages publishes the main branch root. The .nojekyll file keeps the export unchanged by Jekyll.

Template source, shared product data, and maintenance tools are maintained separately in the Visual Math promotion project. To update, build that website with SITE_URL=https://oranipost.github.io/visual-math/, run npm --prefix website run check and npm --prefix website run export:pages, then review and push this export. Do not upload private coordination files, account profiles, raw recordings, or QA evidence.
